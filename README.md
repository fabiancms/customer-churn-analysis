# Telco Customer Churn Analysis

## Overview

This project analyzes customer churn in a telecommunications company to
identify the main factors associated with customer attrition, understand
customer segments with higher churn risk, and support data-driven
retention strategies.

The analysis combines SQL, Python and Power BI to transform raw customer
data into actionable business insights.

## Business Objective

The main objective is to answer questions such as:

-   How many customers are active and how many have churned?
-   What is the overall churn rate?
-   Which customer characteristics are associated with higher churn?
-   How does churn vary by internet service?
-   Which customer segments represent the greatest retention
    opportunity?
-   What actions could the business consider to reduce customer churn?

## Analysis Workflow

The project follows a complete data analytics workflow:

**1. Data preparation**

The source data was reviewed to understand its structure, data types,
missing values and potential inconsistencies.

**2. Data cleaning**

The dataset was prepared for analysis by handling data quality issues
and ensuring that the relevant variables could be used consistently
across SQL, Python and Power BI.

**3. Exploratory Data Analysis**

Python was used to investigate customer behavior and identify patterns
related to churn.

**4. SQL Analysis**

SQL queries were used to segment customers and answer business questions
from the structured dataset.

**5. Power BI Dashboard**

The final analysis was transformed into an interactive Power BI
dashboard containing KPIs, charts and filters designed for business
users.

## Dashboard

The Power BI dashboard focuses on the main customer-retention KPIs,
including:

-   Total Customers
-   Churned Customers
-   Active Customers
-   Churn Rate
-   Churn by Internet Service
-   Customer segmentation and churn patterns

Dashboard screenshots are available in the `images/` folder.

## Business Recommendations

Based on the analysis, the project can support initiatives such as:

-   Prioritizing high-risk customer segments for retention campaigns.
-   Investigating service characteristics associated with elevated
    churn.
-   Designing targeted offers according to customer profiles.
-   Monitoring churn rate and customer behavior through recurring
    dashboards.
-   Using customer segmentation to allocate retention efforts more
    efficiently.
